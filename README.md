# Lucknow Lead Gen Dashboard

Businesses without websites in **Lucknow** — verified through 5-phase protocol.

## How it works
1. **Discover**: Google Maps scraping via Playwright for 20 categories
2. **Detail Extraction**: gmaps-scraper batch for full place details
3. **Verification**: 5-phase protocol (domain check, 3-engine search, social media, entity matching, WHOIS)

## Files
- `index.html` — Interactive dark-mode dashboard
- `lucknow_verified.csv` — Raw verified leads data
